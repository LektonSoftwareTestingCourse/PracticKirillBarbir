1. Область и подход
- Область тестирования - СМП в части ядра процессинга: сервис авторизации и сервис управления картами
- Подход к тестированию: уровни - модульное, интеграционное, API, E2E
- Техники тест-дизайна: классы эквивалентности, граничные значения, попарное тестирование
- Техники и инструменты автоматизации:
  - ЯП: Java
  - Фреймворки: JUnit 5, Mockito, Spring Boot Test, Testcontainers, RestAssured
  - Отчётность: Allure Framework

2. Критерии входа и выхода
- Критерии входа:
  - Тестовая среда и сервисы успешно разворачиваются
  - Health-check сервисов возвращает HTTP 200 и статус ok
  - В базе данных создано минимум 50 тестовых карт разных статусов
- Критерии выхода:
  - Все тест-кейсы и чек-листы пройдены успешно
  - Нет открытых дефектов
  - Покрытие unit-тестами написано для основной бизнес-логики и алгоритмов ядра

3. Критерии приостановки и возобновления
- Приостановка тестирования:
  - Сервисы перестали запускаться или health-check возвращает ошибку
  - Более половины тест-кейсов высшего приоритета падают по одной и той же причине
- Возобновление тестирования:
  - Причина приостановки исправлена
  - Smoke-прогон после исправления прошёл успешно
  - Критерии входа снова выполняются

4. Ресурсы, расписание, риски и метрики
- Ресурсы:
  - Электронно-вычислительное устройство с настроенным окружением
- Расписание:
  1. тестовая документация
  2. unit-тесты
  3. API-тесты
  4. интеграционные тесты
  5. E2E-тесты
- Метрики, по которым контролируем ход тестирования:
  - Процент выполнения тест-кейсов по приоритетам
  - Количество и серьёзность найденных дефектов
  - Покрытие написанными unit и API тестами
- Риски и меры противодействия:
  - В предполагаемых подходах тестирования нет рисков
